# API التطبيق — التعبئات (v1)

المادة تنباع **بالباكيت الكامل بس**. الباكيت بيه **20 أو 24 قطعة**، حسب المادة، وتعبئة المادة ما تتغيّر.
المخزون ينحسب **بالقطعة**، ويطلع **بالدرزن** (الدرزن = 12 قطعة). وسعر البيع **للدرزن**.
الهيدرات والتوكن مشروحين بـ [login.md](login.md).

---

## عرض التعبئات

```http
GET /api/v1/packages
Authorization: Bearer <التوكن>
Accept-Language: ar
```

يحتاج صلاحية `app.checkout`، وبدونها يرجع `403`.

### الجواب — `200`

```json
{
  "data": [
    { "value": "packet", "label": "باكيت", "size": null }
  ]
}
```

| الحقل | معناه |
|---|---|
| `value` | مفتاح التعبئة |
| `label` | اسمها بلغة `Accept-Language` |
| `size` | دايماً `null`، لأن حجم الباكيت من المادة: `pieces_per_packet` بـ [items.md](items.md) |

### شلون يصير البيع

1. البائع يختار المادة، والدرجة وتشكيلة الألوان إذا إلها (شوف [items.md](items.md#أنواع-الباكيت-packet_types))، ويكتب **عدد الباكيتات**، مثلاً **7**.
2. القطع = الباكيتات × `pieces_per_packet` مال المادة = `7 × 20` = **140 قطعة**.
3. الدرازن = القطع ÷ 12 = **11.67 درزن**.
4. السعر = الدرازن × `sale_price` (سعر الدرزن) = `11.67 × 15,000` = **175,000**.
5. دز البند ويا البيع (شوف [orders.md](orders.md#البيع-الچيك-اوت)):

```json
{ "item_id": 3, "packets": 7 }
```

- مادة `pieces_per_packet` مالتها `null` **ما تنباع**.
- لا تخلي البائع يختار باكيتات أكثر من `available_packets` مال النوع اللي اختاره.
